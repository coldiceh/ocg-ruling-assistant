# 遊戯王OCG AI裁定

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

[オンライン版を使う](https://coldiceh.github.io/ocg-ruling-assistant/) · [問題を報告する](https://github.com/coldiceh/ocg-ruling-assistant/issues)

遊戯王OCG AI裁定は、カードテキスト、公開されているルール資料、公式 Q&A を使って裁定問題を分析し、回答の根拠を確認できる OCG プレイヤー向けツールです。

KONAMI の公式プロジェクトではなく、公式大会におけるジャッジの判断に代わるものでもありません。

## できること

- カードの発動、チェーン、効果処理、タイミング、代替処理などの問題を分析します。
- 質問に含まれるカードとカードテキストを確認し、不確かな箇所をユーザーが補足・修正できます。
- 裁定分析に使うモデルと思考レベルを選べます。
- 結論、分析理由、参照元、さらに確認が必要な点を表示します。
- 裁定回答を生成せず、整理された証拠だけをダウンロードして、別の AI に自分で質問できます。
- 新しいカードがまだデータベースに収録されていない場合、ユーザーが貼り付けた完全な効果テキストをもとに未確認の分析を行います。

## 使い方

1. その時点の盤面、操作の順番、確認したい裁定点を含め、質問を詳しく入力します。
2. 認識されたカードとカードテキストを確認します。抜けがある場合や新しいカードが未収録の場合は、完全な効果テキストを補足・修正します。
3. 裁定モデルと思考レベルを選び、分析を開始します。
4. 結論、理由、引用された根拠を読み、必要に応じて参照元の原文を確認します。
5. 資料だけが必要な場合は、整理された証拠をダウンロードし、任意の別の AI で分析できます。

AI はルールを誤読したり、条件を見落としたり、誤った結論を出したりすることがあり、回答の正しさは保証されません。表示された根拠を確認し、大会では公式資料と現地ジャッジの判断に従ってください。
