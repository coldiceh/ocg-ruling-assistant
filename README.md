# 游戏王 OCG AI裁定 / Yu-Gi-Oh! OCG AI Rulings

[中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

[在线使用](https://coldiceh.github.io/ocg-ruling-assistant/) · [问题反馈](https://github.com/coldiceh/ocg-ruling-assistant/issues)

游戏王 OCG AI裁定面向所有 OCG 玩家，帮助你结合卡片文本、公开规则资料和官方 Q&A 分析裁定问题，并查看回答依据。

它不是 KONAMI 官方项目，也不替代正式比赛的现场裁判。

## 可以做什么

- 分析卡片发动、连锁、效果处理、时点、替代处理等问题。
- 确认问题涉及的卡片与卡片文本，发现不确定处时由你补充或更正。
- 选择用于裁定分析的模型和思考档位。
- 展示结论、分析理由、引用来源和仍需确认的地方。
- 只下载整理好的证据，交给你选择的其他 AI 自行提问。
- 在数据库暂未收录新卡时，根据用户粘贴的完整效果文本进行未确认分析。

## 使用方法

1. 输入完整问题，包括当时的场面、操作顺序和希望确认的裁定点。
2. 检查系统识别出的卡片和卡片文本；如有遗漏或新卡未收录，请补充完整效果文本。
3. 选择裁定模型和思考档位，然后开始分析。
4. 阅读结论、理由和引用依据，必要时打开来源核对原文。
5. 如果只需要资料，可以下载整理好的证据，再自行交给其他 AI 分析。

AI 可能误读规则、遗漏条件或给出错误结论，无法保证回答正确。请结合显示的依据核对；正式比赛请以现场裁判与官方资料为准。
