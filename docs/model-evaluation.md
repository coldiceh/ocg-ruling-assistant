# 模型实验评测

## 固定实验集

核心实验集位于：

`data/test/admin-model-lab-evaluations.json`

目前固定题集共 9 题，覆盖：

1. 特殊召唤手续产生的除外事件与后续诱发连锁。
2. 月光银狗限制的效果实例生命周期。
3. 闪刀姬＝零萝与千查万别的分段处理和状态重算。
4. 复制效果与卡面印刷名称记述的区别。
5. 效果被无效后，“每回合使用次数”与未处理限制的区别。
6. 阿不思支付 COST 后场上抗性即时重算，以及处理时融合素材合法性。
7. 从手牌发动陷阱卡时的发动区域与连锁响应条件。
8. 效果改写后破坏事件的来源归因与后续诱发条件。
9. 正在发动且处理后通常送去墓地的通常陷阱，能否满足返回手牌类效果的发动合法性。

这些题不是卡名特判代码，而是用于比较检索完整性、模型推理和结构校验是否覆盖相应机制。

## 比较原则

同轮模型比较必须使用同一个 Evidence Snapshot。不得为不同模型重新检索后直接比较答案，否则无法区分是检索差异还是推理差异。

每个结果分别评估：

- 卡名是否全部解析；
- 是否命中直接官方资料；
- 是否保留冲突和未解析候选；
- 最终 verdict 是否正确；
- 后续处理是否完整；
- 时间线和事件归因是否正确；
- 证据引用是否真实支持 claim；
- 结构校验是否通过；
- Token、费用和延迟；
- 人工评分与备注。

## 人工评分

建议使用：

- `correct`
- `partially_correct`
- `incorrect`
- `needs_review`

评分不得直接修改历史模型输出。修正意见作为独立记录保存，并可导出为后续回归题草稿。

## 生产切换门槛

公开版不能因为管理实验室接入 GPT 就自动切换。至少需要：

- 固定实验集无关键错误；
- 表达变体测试没有明显退化；
- 引用与结构校验稳定；
- 费用和延迟可接受；
- 管理员明确批准具体模型、effort、mode 和 promptVersion。
