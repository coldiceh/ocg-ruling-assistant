# 公开问答与管理实验隔离

## 公开路径不变

本轮不改变普通用户入口的 Provider 和默认请求：

- 公共页面仍调用 `/api/answer`；
- 默认仍是现有 DeepSeek RAG；
- 公共请求不能选择 OpenAI；
- OpenAI 故障不能使公共问答失效；
- 管理实验失败不能覆盖公开答案版本。

## 管理路径

管理功能使用独立接口：

- `/api/admin-auth`
- `/api/admin-queries`
- `/api/admin-model-lab`

所有管理接口必须使用管理员会话。`?admin=1` 只控制管理组件是否显示，访问者即使手工添加该参数也不会获得数据或模型调用权限。

## 数据隔离

公共响应不得包含：

- OpenAI Key 或 Key 是否以可推断形式存在；
- 管理员密码、会话 Token、CSRF Token；
- Redis Token；
- 上游敏感错误体；
- 其他管理员的私有运行内容。

管理导出只在认证后生成。导出应包含可复现实验所需的模型配置、Evidence Snapshot ID、结果、计量和人工评分，但必须过滤 Secret。

## 上线顺序

1. 先部署认证与管理接口，保持实验室开关关闭。
2. 配置精确 Origin、Redis 和会话密码并验证登录/注销。
3. 配置 OpenAI Key，打开管理实验开关。
4. 用 mock 和小规模人工实验验证异步运行、取消、恢复和费用记录。
5. 运行固定评测集。
6. 只有明确批准后，才另开任务讨论是否更改公开默认模型。
